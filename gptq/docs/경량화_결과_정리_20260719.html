02발견: 압축할 때 쓰는 데이터의 언어가 품질을 가른다

GPTQ 압축은 "보정용 데이터"를 쓰는데, 관례대로 영어 데이터만 쓰면 한국어 실력만 나빠진다. 한국어 데이터를 섞으니 손상이 1/3로 줄었다. (11B 실험, 숫자는 한국어 손상 정도 — 낮을수록 좋음)

04왜 NF4 방식인가 & 이후 계획

  • 보정 데이터가 필요 없다 — 위 02의 언어 편향 문제가 아예 생기지 않음
  • 모델 전체가 압축된다 — 11B에서 발목을 잡았던 이미지 처리 부분까지 전부 4bit
  • 적용이 쉽다 — 설정 코드 3줄이면 끝
